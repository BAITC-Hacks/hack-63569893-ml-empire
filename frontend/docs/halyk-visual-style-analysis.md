# Визуальный стиль Halyk для Voice Router

## Назначение документа

Документ фиксирует визуальные паттерны сайта Halyk Bank по предоставленным скриншотам и переводит их в практические правила для веб-интерфейса Voice Router.

Анализ основан на трёх скриншотах публичного сайта Halyk: главная страница на казахском языке, каталог кредитов и кредитный калькулятор. Значения цветов измерены по изображениям и являются приближёнными. Это не официальный брендбук Halyk.

## Краткий вывод

Визуальный язык Halyk строится на пяти принципах:

1. Большое светлое пространство и спокойная нейтральная основа.
2. Глубокий зелёный как главный цвет бренда, навигации и выбранных состояний.
3. Яркая мята как цвет наиболее важного действия.
4. Крупные простые формы с умеренным скруглением и почти без теней.
5. Чёткая чёрная типографика, в которой иерархия создаётся размером и насыщенностью, а не декоративными эффектами.

Для Voice Router следует использовать этот язык в более сдержанном продуктовом режиме: белый и холодный светло-серый должны занимать большую часть экрана, Halyk green использоваться для активных элементов, а яркая мята только для главного действия текущего этапа.

### 1.2 Цветовое соотношение

Для продуктового интерфейса Voice Router рекомендуется следующее визуальное распределение:

- 65–75%: белый основной фон;
- 15–25%: холодные светло-серые поверхности;
- 6–10%: Halyk Green;
- до 2%: Bright Mint;
- до 3%: семантические цвета ошибок, предупреждений и срочности.

Большая зелёная поверхность допустима в одном фокусном месте, например в состоянии активного звонка или на стартовом экране. Панель супервизора не должна быть полностью зелёной: большое количество технических данных лучше читается на белой или светло-серой поверхности.

### 1.3 Градиенты

На скриншотах градиент используется только на крупных брендовых блоках. Он строится внутри зелёной гаммы и не заменяет структуру интерфейса.

Рекомендуемое направление:

```css
background: linear-gradient(145deg, #00805f 0%, #069477 58%, #0dac88 100%);
```

Градиент подходит для:

- стартового экрана звонка;
- крупного блока с активным голосовым состоянием;
- демонстрационного hero-блока.

Градиент не следует использовать:

- в каждой карточке;
- в таблице трассировки;
- в тексте;
- в статусах ошибок;
- в небольших кнопках и фильтрах.

### 1.4 Дополнительные семантические цвета

На сайте Halyk брендовый зелёный отвечает за позитивное и активное состояние, но Voice Router требует более широкого набора статусов.

| Состояние | Рекомендуемый цвет | Использование |
| --- | --- | --- |
| Успех | `#00805F` | Действие выполнено, соединение установлено |
| Активное прослушивание | `#00805F` | Микрофон включён, пользователь говорит |
| Срочный сценарий | `#D98200` | `urgent`, срочная передача, важное предупреждение |
| Ожидание подтверждения | `#B76A00` | Необратимое действие ещё не выполнено |
| Ошибка | `#C83C3C` | Ошибка STT, TTS, сети или действия |
| Информация | `#276E8C` | Техническая информация без оценки |
| Неактивное состояние | `#A5AAA8` | Отключённый контрол, пустое состояние |

Красный нельзя заменять зелёным ради брендовой целостности. Ошибка и запись микрофона должны различаться не только цветом, но также текстом, иконкой и формой состояния.

## 2. Светлая нейтральная основа

Главная особенность интерфейса Halyk не зелёный цвет сам по себе, а объём свободного белого пространства вокруг него.

Наблюдаемые паттерны:

- основной фон белый;
- карточки имеют холодный светло-серый фон;
- белые поля размещаются внутри серых поверхностей;
- границы тонкие и малоконтрастные;
- тени отсутствуют или почти незаметны;
- блоки отделяются расстоянием и разницей фона.

Для Voice Router это означает:

- основной canvas должен быть белым;
- история диалога может находиться на белом фоне;
- панель супервизора может использовать `#F1F2F6` как базовую поверхность;
- отдельные записи трассировки должны разделяться расстоянием или тонкой границей;
- не следует помещать каждое поле в отдельную тяжёлую карточку с тенью.

## 3. Типографика

### 3.1 Общий характер

На скриншотах используется нейтральный современный sans-serif без декоративных деталей. Шрифт воспринимается как близкий к системному UI-шрифту или современному grotesk.

Основные свойства:

- чёрный или почти чёрный основной текст;
- крупные заголовки с умеренной насыщенностью;
- нормальный регистр без повсеместного uppercase;
- короткие подписи серым цветом;
- числовые значения крупнее и насыщеннее своих подписей;
- кнопки имеют короткие прямые формулировки.

Для реализации подходит стек:

```css
font-family: Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
```

Если официальный шрифт Halyk недоступен, не следует подменять его декоративным display-шрифтом.

| Заголовок рабочей области | 24 px | 600 | 1.2 |

Для русского и казахского текста следует заранее проверить символы `Ә`, `Ғ`, `Қ`, `Ң`, `Ө`, `Ұ`, `Ү`, `Һ`, `І` во всех выбранных начертаниях.

## 4. Сетка и композиция

### 4.1 Контейнер

Контент сайта Halyk располагается в широком центральном контейнере. На больших экранах остаются заметные поля слева и справа.

Рекомендация для Voice Router:

```css
max-width: 1440px;
margin-inline: auto;
padding-inline: 32px;
```

Для ноутбука с меньшей шириной боковые поля можно уменьшать до 20–24 px.

### 4.2 Ритм пространства

Страница использует крупные интервалы между смысловыми секциями и более компактные интервалы внутри контролов.

Рекомендуемая шкала:

```text
4, 8, 12, 16, 24, 32, 48, 64, 80 px
```

Основные правила:

- 8 px между иконкой и текстом;
- 12–16 px между связанными элементами;
- 24 px между группами полей;
- 32 px внутреннего пространства рабочей панели;
- 48–64 px между крупными секциями;
- не использовать одинаковый padding у каждого блока без учёта его роли.

### 4.3 Двухпанельный Voice Router

Для десктопа лучше использовать соотношение:

```text
Диалог клиента: 58–62%
Панель супервизора: 38–42%
```

Обе области должны восприниматься как части одного рабочего пространства. Между ними нужен один явный разделитель или разница фона, а не две независимые карточки с тяжёлыми тенями.

На узком экране панели располагаются вертикально:

1. диалог;
2. управление голосом;
3. выбранный сценарий;
4. подробная трассировка.

## 5. Формы, радиусы и границы

### 5.1 Скругления

На Halyk используются крупные, но не чрезмерно круглые формы:

- крупные промоблоки: примерно 28–36 px;
- рабочие карточки: примерно 18–24 px;
- поля и кнопки: примерно 10–14 px;
- фильтры и вкладки: полный pill-radius.

Рекомендуемые токены:

```css
--radius-control: 12px;
--radius-panel: 20px;
--radius-hero: 32px;
--radius-pill: 999px;
```

### 5.2 Где использовать pill

Pill-форма подходит для:

- фильтров;
- выбора режима;
- языкового переключателя;
- компактного статуса;
- сценария или приоритета.

Pill-форма не нужна для:

- каждой основной кнопки;
- больших панелей;
- строк диалога;
- сложных действий подтверждения.

### 5.3 Тени

Сайт почти не использует заметные тени. Глубина создаётся фоном и отступами.

Для Voice Router:

- базовые панели без тени;
- выпадающее меню может иметь лёгкую тень;
- активное всплывающее состояние может иметь одну мягкую тень;
- не использовать несколько уровней elevation одновременно.

## 6. Кнопки и состояния выбора

### 6.1 Основная кнопка

Основная кнопка на светлом фоне:

- Halyk Green `#00805F`;
- белый текст;
- средняя насыщенность;
- компактная высота 44–48 px;
- радиус около 12 px.

### 6.2 Акцентная кнопка

Bright Mint применяется на насыщенной зелёной поверхности. В Voice Router это может быть:

- «Начать звонок» на зелёном стартовом блоке;
- «Подтвердить действие» в явном confirmation-состоянии.

Мятную кнопку не следует повторять много раз на одном экране. Иначе пропадает приоритет.

### 6.3 Вторичная кнопка

- белый или светло-серый фон;
- зелёный или тёмный текст;
- тонкая граница;
- тот же радиус и высота, что у основной кнопки.

### 6.4 Выбранное состояние

На сайте Halyk выбранный фильтр становится зелёным, а невыбранные остаются светло-серыми. Этот паттерн подходит для:

- вкладок «Диалог» и «Трассировка» на мобильном;
- фильтров событий;
- выбора текстового или голосового режима;
- переключателя языка интерфейса.

Для каждого интерактивного элемента необходимо определить состояния:

- default;
- hover;
- focus-visible;
- active;
- selected;
- disabled;
- loading;
- error.

## 7. Навигация и шапка

Сайт Halyk использует двухуровневую шапку:

- верхний уровень для аудитории, языка и сервисных действий;
- нижний уровень для основной продуктовой навигации.

Для Voice Router полное копирование банковского меню не нужно. Достаточно компактной продуктовой шапки:

- логотип или текстовая марка Halyk;
- название `Voice Router`;
- состояние соединения;
- язык интерфейса;
- кнопка нового звонка или завершения сессии.

Шапка должна оставаться светлой. Зелёный используется для логотипа, активного состояния и главного действия.

## 8. Карточки и панели

### 8.1 Что видно на сайте

Карточки Halyk обычно:

- широкие;
- имеют светло-серый фон;
- содержат одну основную задачу;
- используют крупный заголовок;
- имеют изображение справа и текст слева;
- не перегружены рамками и тенями.

### 8.2 Перенос в Voice Router

Карточкой следует считать только самостоятельный смысловой объект:

- текущий выбранный сценарий;
- запрос подтверждения;
- передача оператору;
- ошибка, требующая решения пользователя.

Не следует делать отдельную карточку для каждого технического поля трассировки. Транскрипт, язык, слоты, действия и задержки лучше объединить в одну структурированную запись реплики.

## 9. Изображения и графика

Halyk использует два типа графики:

1. Реалистичные рекламные композиции с людьми, телефонами и 3D-объектами.
2. Предметные иллюстрации банковских продуктов на светло-серых карточках.

Для Voice Router рекламная фотография необязательна. Она может появиться только:

- на стартовом экране;
- в презентационном режиме;
- в onboarding-блоке до начала звонка.

В рабочем интерфейсе лучше использовать:

- простые контурные иконки;
- форму аудиоволны;
- индикатор уровня микрофона;
- компактную временную шкалу задержки;
- цветовые статусы сценариев.

Не рекомендуется использовать футуристические головы роботов, неоновые сети, мозг из частиц или типовые AI-иллюстрации. Они конфликтуют со спокойным и прикладным характером Halyk.

## 10. Иконки

Наблюдаемый стиль:

- простые контурные иконки;
- одинаковая толщина штриха;
- минимум деталей;
- зелёный для активных действий;
- серый или чёрный для нейтральных действий.

Для реализации желательно выбрать одну библиотеку и не смешивать разные наборы. Подходят Lucide или Phosphor в одном выбранном весе.

## 11. Motion и обратная связь

Сайт выглядит статично и уверенно. Движение должно объяснять состояние, а не украшать экран.

Для Voice Router нужны:

- мягкое изменение уровня микрофона во время речи;
- появление промежуточного транскрипта без скачка layout;
- плавное раскрытие подробностей трассировки;
- короткий переход выбранного сценария;
- явное, но спокойное подтверждение выполненного действия.

Рекомендуемая длительность:

```text
150–220 мс для hover и выбора
200–280 мс для раскрытия панели
```

Следует учитывать `prefers-reduced-motion` и отключать декоративное движение аудиоволны.

## 12. Применение стиля к основным зонам Voice Router

### 12.1 Старт звонка

- один крупный зелёный блок;
- короткий заголовок;
- краткое пояснение о русском и казахском;
- одна мятная кнопка «Начать звонок»;
- текстовый канал виден как вторичный вариант;
- без нескольких конкурирующих CTA.

### 12.2 Активный звонок

- белый основной фон;
- крупная зелёная кнопка микрофона;
- рядом понятный текст состояния;
- аудиоволна только при реальной записи;
- история разговора занимает большую часть левой области;
- текстовый ввод закреплён внизу как резервный канал.

### 12.3 Панель супервизора

- светло-серый фон панели;
- основной сценарий выделен зелёным;
- дополнительные сценарии показаны нейтральными pill-элементами;
- `urgent` использует янтарный цвет;
- обоснование остаётся обычным читаемым текстом;
- слоты и действия организованы списками, а не набором вложенных карточек;
- задержка показана горизонтальной шкалой этапов.

### 12.4 Подтверждение действия

- отдельный компактный блок внутри текущего диалога;
- название действия и аргументы;
- основная кнопка подтверждения;
- вторичная кнопка отказа;
- явная подпись «Действие ещё не выполнено»;
- после ответа сервера блок меняет состояние на выполненное или отменённое.

### 12.5 Передача оператору

- спокойный информационный экран без тревожного красного фона;
- янтарный или нейтральный статус;
- краткая причина;
- название очереди;
- переданный контекст;
- текущее состояние соединения.

- визуальную тишину и большое свободное пространство;
- единообразное отображение русского и казахского языков;
- минимум теней;
- простые контурные иконки.

## 15. Что не следует копировать буквально

- двухуровневое банковское меню;
- большие рекламные баннеры внутри рабочего экрана;
- фотографии и 3D-композиции в панели супервизора;
- крупные пустые интервалы, которые уменьшают объём видимой трассировки;
- зелёный фон у всех панелей;
- промостиль для технических метрик;
- слишком крупные карточки каталога для каждой реплики.

## 16. Итоговое направление Voice Router

Интерфейс должен восприниматься как продукт Halyk, а не как отдельный AI-стартап. Его характер:

- надёжный;
- спокойный;
- современный;
- понятный без объяснений разработчика;
- локализованный для русского и казахского;
- технически прозрачный для супервизора.

Лучшее сочетание для рабочего экрана: белая основа, светло-серая панель трассировки, Halyk Green для активного сценария и микрофона, Bright Mint для одного главного действия, чёрный текст и тонкие нейтральные границы.
